P1055 [NOIP 2008 普及组] ISBN 号码

P1055 [NOIP 2008 普及组] ISBN 号码

题目描述

每一本正式出版的图书都有一个 ISBN 号码与之对应，ISBN 码包括 $9$ 位数字、$1$ 位识别码和 $3$ 位分隔符，其规定格式如 x-xxx-xxxxx-x，其中符号 - 就是分隔符（键盘上的减号），最后一位是识别码，例如 0-670-82162-4就是一个标准的 ISBN 码。ISBN 码的首位数字表示书籍的出版语言，例如 $0$ 代表英语；第一个分隔符 - 之后的三位数字代表出版社，例如 $670$ 代表维京出版社；第二个分隔符后的五位数字代表该书在该出版社的编号；最后一位为识别码。

识别码的计算方法如下：

首位数字乘以 $1$ 加上次位数字乘以 $2$ ……以此类推，用所得的结果 $ \bmod 11$，所得的余数即为识别码，如果余数为 $10$，则识别码为大写字母 $X$。例如 ISBN 号码 0-670-82162-4 中的识别码 $4$ 是这样得到的：对 067082162 这 $9$ 个数字，从左至右，分别乘以 $1,2,\dots,9$ 再求和，即 $0\times 1+6\times 2+……+2\times 9=158$，然后取 $158 \bmod 11$ 的结果 $4$ 作为识别码。

你的任务是编写程序判断输入的 ISBN 号码中识别码是否正确，如果正确，则仅输出 Right；如果错误，则输出你认为是正确的 ISBN 号码。

输入格式

一个字符序列，表示一本书的 ISBN 号码（保证输入符合 ISBN 号码的格式要求）。

输出格式

一行，假如输入的 ISBN 号码的识别码正确，那么输出 Right，否则，按照规定的格式，输出正确的 ISBN 号码（包括分隔符 -）。

P5715 【深基3.例8】三位数排序

方法 2：列表 sort () 方法（最简洁，实战优先）

利用 Python 列表的sort()方法原地排序（直接修改列表），是最符合 Python 风格的简洁写法，新手优先掌握。

关键解释：

  • list(map(int, input().split()))：将输入的 3 个字符串转成整数，再封装成列表（如[1,14,5]）；
  • nums.sort()：列表内置的排序方法，原地修改列表（无返回值），默认按升序排列；
  • ' '.join(map(str, nums))：将列表中的整数转成字符串，再用空格连接成一行（如[1,5,14]→"1 5 14"），比逐个打印更通用。

方法 3：sorted () 函数法（返回新列表，不修改原列表）

使用 Python 内置的sorted()函数，返回新的排序后列表（原列表不变），区分sort()和sorted()的核心差异。

关键解释：

  • sorted(nums)：内置函数，接收可迭代对象（如列表），返回升序排列的新列表，不修改原列表；

  • vs

    ：

    • sort()：列表方法，原地排序，无返回值（适合直接修改原列表）；
    • sorted()：内置函数，返回新列表，原列表保留（适合需要保留原始数据的场景）。

方法 4：数学最值法（练习 min/max 函数）

用min()找最小值、max()找最大值，中间值 = 总和 - 最小值 - 最大值，适合练习内置最值函数的用法。

关键解释：

  • min(a,b,c)/max(a,b,c)：Python 内置函数，直接返回多个参数中的最小 / 最大值；
  • 中间值计算逻辑：因为只有三个数，总和减去最小和最大，剩下的就是中间值（适合 3 个数的场景，简单高效）；
  • 注意：此方法仅适用于恰好 3 个数的排序，扩展到更多数时不适用，但本题场景下非常简洁。
